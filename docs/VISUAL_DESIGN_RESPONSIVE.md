# Web 视觉设计与响应式工作台

## 目标与边界

本轮将原有功能型 Demo 整理为统一的数据查询工作台，保持既有 API、RBAC、SSE、分页、导出、图表、审计与 Trace 行为不变。页面仍是原生 HTML/CSS/JavaScript，不依赖前端构建工具；它提升信息架构和可用性，但不等同于已经完成浏览器兼容矩阵、无障碍认证或专业设计走查。

## 页面结构

- 顶部全局栏：当前数据源、模型运行配置、运营中心、用户权限、新会话和登录用户。
- 左侧工作区：数据源状态与管理、历史会话、快捷问题。
- 中央查询画布：自然语言输入、SSE 状态、最终答案、SQL、分页表格、CSV、图表和人工反馈。
- 右侧 Trace：直接消费真实 SSE 节点事件，展示节点顺序、耗时和最终运行指标。
- 管理抽屉：数据源、授权、用户管理互斥打开，减少页面跳转。
- 运营中心：聚合指标、14 日趋势、查询 Trace 明细、资源审计、反馈和在线评测。

## 响应式规则

| 视口 | 布局 |
| --- | --- |
| `> 1280px` | 数据源 / 查询 / Trace 三栏同时展示 |
| `921–1280px` | 左侧栏 + 查询画布，Trace 作为右侧抽屉 |
| `641–920px` | 查询画布，导航为左抽屉，Trace 为右抽屉 |
| `<= 640px` | 单列移动布局，结果工具、图表配置和反馈区纵向排列 |

移动端导航保留按权限显示的运营中心与用户权限入口。抽屉支持遮罩关闭和 `Esc` 关闭，管理弹层支持点击背景关闭。

## 关键交互

- 问题输入框按内容自动增高，最大高度受限；`Ctrl/Command + Enter` 可执行。
- 示例问题只填入实际问题文本，不携带视觉序号。
- SQL 支持安全复制到剪贴板，并显示短暂结果反馈。
- 新建会话会清除当前结果和 Trace，并恢复初始引导状态。
- 会话选择、示例选择和数据源切换会在窄屏自动收起导航。
- 运营中心的查询记录可展开节点时间线、Request ID、Trace ID、检索表与错误类型。
- `prefers-reduced-motion` 开启时禁用非必要动画；键盘焦点使用清晰描边。

## 项目接入点

- 页面语义结构：`web/index.html`
- 设计变量、组件和断点：`web/styles.css`
- 响应式抽屉、快捷键、复制、Trace 与管理中心交互：`web/app.js`
- 静态资源继续由 `Web_app.py` 和二进制包内嵌目录提供，不新增 Node.js 运行时依赖。

## 验证方法

```bash
node --check web/app.js
python3 -m unittest discover -s tests -v
python3 Test_reward_engine.py
```

浏览器验收建议使用开发者工具依次检查 `1440×900`、`1024×768`、`768×1024`、`390×844`，覆盖登录、数据源切换、查询流、取消、分页、图表、会话恢复、三个管理抽屉和运营中心。当前服务器环境未安装 Chromium/Playwright，因此本轮自动验收覆盖 DOM 选择器、JavaScript 语法、HTTP 静态资源与后台全量回归；视觉像素级跨浏览器测试仍应在 CI 中补充。

## 安全与数据边界

视觉改造没有改变凭证存储和查询权限边界。Trace 仍只展示后端允许的节点元数据；结果数据不会因为图表或复制功能发送给新的第三方服务。运营中心仍受 `audit.read` 权限控制，用户管理仍受 RBAC 控制。
